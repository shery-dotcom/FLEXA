# Progressive Overload Templates for Fat Loss, Hypertrophy, and Strength (Pakistan-Friendly)

## Who This Is For

- Beginners to intermediate gym users
- Training 3-5 days per week
- Home, local gym, or full commercial gym

## How To Use This Sheet

- Pick one primary goal for 8-12 weeks
- Track your top lifts and body metrics weekly
- Progress only one variable at a time

## Overload Variables

| Variable | What To Change            | Typical Range            |
| -------- | ------------------------- | ------------------------ |
| Reps     | Add reps with same weight | +1 to +2 reps per set    |
| Load     | Add weight with same reps | +1.25 kg to +5 kg        |
| Sets     | Add one work set          | +1 set for main movement |
| Tempo    | Slow lowering phase       | 2-4 sec eccentric        |
| Rest     | Reduce rest for density   | -15 to -30 sec           |

## Template A: Fat Loss (Keep Muscle)

## Goal -> Action -> Example

- Goal: Lose 0.25 to 0.75 kg/week while keeping strength
- Action: Keep weights moderate-heavy, add reps first, then load
- Example: Goblet squat 3x10 at 20 kg -> next week 3x11 -> then 3x10 at 22.5 kg

### Weekly Progress Rule

| If You Hit Target Reps On All Sets | Next Session                          |
| ---------------------------------- | ------------------------------------- |
| Yes                                | Add 1-2 reps total OR +1.25 to 2.5 kg |
| No                                 | Keep load same and repeat             |

### Session Skeleton (4 Days)

- Day 1: Upper push + 10-15 min incline walk
- Day 2: Lower + core
- Day 3: Upper pull + 10-15 min bike
- Day 4: Full body circuit

### Deload Trigger

- Performance drops for 2 straight weeks
- Action: Reduce volume by 30-40% for 1 week

## Template B: Hypertrophy (Muscle Gain)

## Goal -> Action -> Example

- Goal: Increase muscle size with stable technique
- Action: Use double progression in 6-12 rep range
- Example: Bench press 4x8 at 60 kg -> progress to 4x12 -> increase to 62.5 kg and restart at 4x8

### Hypertrophy Progression Grid

| Exercise Type | Sets | Reps  | Progression Priority  |
| ------------- | ---- | ----- | --------------------- |
| Compound      | 3-5  | 6-10  | Reps first, then load |
| Accessory     | 2-4  | 10-15 | Reps first, then load |
| Isolation     | 2-4  | 12-20 | Reps, tempo, squeeze  |

### Weekly Decision Rules

- If form is clean and RIR 1-2: increase reps next session
- If top rep range reached on all sets twice: add load
- If joints feel irritated: keep load, increase control and pause

## Template C: Strength (Power Focus)

## Goal -> Action -> Example

- Goal: Improve 3-5 rep strength in squat, bench, deadlift or alternatives
- Action: Use top set + back-off sets
- Example: Top set deadlift 1x4 at 120 kg, back-off 3x4 at 108 kg (90%)

### Strength Progression Rule

| Week | Top Set Target | Back-Off      |
| ---- | -------------- | ------------- |
| 1    | 1x5 @ RPE 7-8  | 3x5 at 88-90% |
| 2    | 1x4 @ RPE 8    | 3x4 at 88-90% |
| 3    | 1x3 @ RPE 8-9  | 4x3 at 88-90% |
| 4    | Deload         | 2x3 light     |

## Beginner-Friendly Pakistan Gym Example

- If your gym has fixed dumbbells only:
- Use rep progression up to top range before changing exercise difficulty
- Example ladder:
- Incline DB press 15 kg x 10 -> 12 -> 14
- Then move to 17.5 kg x 8 and rebuild reps

## Common Problems -> Cause -> Fix

| Problem              | Likely Cause                 | Fix                                 |
| -------------------- | ---------------------------- | ----------------------------------- |
| Not progressing      | Changing plan every week     | Keep same core lifts for 6-8 weeks  |
| Constant soreness    | Too much volume + poor sleep | Reduce sets by 20%, sleep 7+ hours  |
| Strength drop in cut | Aggressive calorie deficit   | Keep deficit moderate, protein high |

## Tracking Checklist (Weekly)

- Body weight trend (3-day average)
- Main lift performance (top set + total reps)
- Sleep quality (1-5)
- Steps/day
- Protein intake consistency

## Minimum Recovery Standards

- Protein: 1.6-2.2 g/kg body weight
- Sleep: 7-9 hours
- Water: 30-40 ml/kg body weight
- Rest day: 1-2 per week

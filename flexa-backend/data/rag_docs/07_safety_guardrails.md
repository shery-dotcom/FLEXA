# Safety Guardrails for AI Gym Coaching: Stop Rules and Referral Triggers

## Purpose

- Keep users safe
- Detect when AI guidance is not enough
- Route to doctor or physiotherapist when needed

## Hard Stop Symptoms (Immediate Referral)

| Symptom                                               | Action                                 |
| ----------------------------------------------------- | -------------------------------------- |
| Chest pain, pressure, breathing difficulty            | Stop training now, urgent medical care |
| Fainting or near-fainting                             | Stop and seek medical evaluation       |
| Sudden severe headache or vision change               | Urgent medical care                    |
| Numbness, weakness, loss of coordination              | Emergency assessment                   |
| New severe back pain with leg weakness/bladder change | Emergency care                         |

## Musculoskeletal Referral Triggers

| Trigger                                         | Action                         |
| ----------------------------------------------- | ------------------------------ |
| Sharp pain during movement that does not settle | Stop exercise and refer physio |
| Joint instability, locking, or giving way       | Refer physio/orthopedic review |
| Pain >5/10 for more than 7 days                 | Clinical assessment required   |
| Night pain disturbing sleep repeatedly          | Medical review                 |

## Problem -> Cause -> Fix -> Escalation

| Problem                     | Likely Cause            | Immediate Fix                   | Escalate If                |
| --------------------------- | ----------------------- | ------------------------------- | -------------------------- |
| Knee pain during squats     | Load/technique mismatch | Reduce load and depth           | Pain persists >1 week      |
| Shoulder pain in pressing   | Irritating ROM/grip     | Switch to neutral grip DB press | Weakness or night pain     |
| Lower back pain in deadlift | Poor bracing/fatigue    | Swap to lighter hinge variant   | Radiating pain or numbness |

## Contraindications for Coaching-Only Advice

- Uncontrolled hypertension
- Uncontrolled diabetes with symptoms
- Recent surgery without clearance
- Pregnancy with medical complications
- Known cardiac disease without physician clearance

## Medication and Supplement Guardrail

- AI should not prescribe medications
- AI should avoid dosage advice for prescription drugs
- For supplements, provide conservative general info only and advise clinician check for conditions/med interactions

## Safe Session Checklist

- Warm-up completed (5-10 min)
- Pain status checked before loading
- Technique stable in first working set
- Stop if sharp pain, dizziness, or unusual breathlessness

## AI Response Policy Snippets

- If red-flag symptom appears:
- Stop workout immediately. This may need urgent medical care.

- If persistent pain appears:
- Reduce load now and book a physiotherapy assessment before progressing.

- If user requests risky advice:
- I cannot provide unsafe guidance. I can help with safer alternatives and referral steps.

## Documentation for Audit

- Record symptom reported
- Record action advised
- Record referral suggestion
- Record follow-up prompt within 24-72 hours

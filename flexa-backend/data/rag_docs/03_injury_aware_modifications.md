# Injury-Aware Training Modifications (Knee, Lower Back, Shoulder)

## Scope

- For mild discomfort and return-to-training adjustments
- Not for severe pain, trauma, or neurological symptoms

## Traffic Light Rule

| Status | Signs                                         | Action                           |
| ------ | --------------------------------------------- | -------------------------------- |
| Green  | Pain 0-2/10, no next-day flare                | Continue with normal progression |
| Yellow | Pain 3-5/10 or stiffness next day             | Reduce load/ROM/volume 20-40%    |
| Red    | Sharp pain, instability, numbness, night pain | Stop and refer to doctor/physio  |

## Knee Pain Modifications

## Problem -> Cause -> Fix

| Problem            | Common Cause           | Fix                                                |
| ------------------ | ---------------------- | -------------------------------------------------- |
| Pain in deep squat | Depth or poor tracking | Box squat, controlled depth, knees track toes      |
| Pain in lunges     | Step length too short  | Reverse lunge, longer stride, torso slight forward |
| Pain in running    | Load spike             | Replace with cycling/rowing for 1-2 weeks          |

### Knee-Friendly Exercise Swaps

| Exercise      | Alternative               | Notes                     |
| ------------- | ------------------------- | ------------------------- |
| Back squat    | Box squat or goblet squat | Use pain-free depth       |
| Leg extension | Spanish squat hold        | Isometric can reduce pain |
| Jump squats   | Sled push or incline walk | Lower impact conditioning |

## Lower Back Modifications

## Problem -> Cause -> Fix

| Problem                         | Common Cause                 | Fix                            |
| ------------------------------- | ---------------------------- | ------------------------------ |
| Pain in deadlift lockout        | Overextension + weak bracing | Neutral lockout, brace 360 deg |
| Pain in bent-over rows          | Long unsupported torso       | Chest-supported row            |
| Morning stiffness after leg day | Too much hinge volume        | Split hinge days, reduce sets  |

### Back-Friendly Swaps

| Exercise              | Alternative                     | Notes                      |
| --------------------- | ------------------------------- | -------------------------- |
| Conventional deadlift | Trap bar deadlift or RDL        | Keep load closer to center |
| Back squat            | Front-foot elevated split squat | Less spinal loading        |
| Good morning          | Hip thrust                      | Reduce shear force         |

## Shoulder Modifications

## Problem -> Cause -> Fix

| Problem               | Common Cause               | Fix                                   |
| --------------------- | -------------------------- | ------------------------------------- |
| Pain overhead         | Poor scapular control      | Landmine press or incline DB press    |
| Pain in bench bottom  | Excessive ROM for shoulder | Floor press, neutral grip DB press    |
| Pain in lateral raise | Too heavy + momentum       | Lighter load, cable raise, slow tempo |

### Shoulder-Friendly Swaps

| Exercise      | Alternative           | Notes                      |
| ------------- | --------------------- | -------------------------- |
| Barbell OHP   | Landmine press        | Shoulder-friendly arc      |
| Barbell bench | Neutral grip DB bench | Better joint position      |
| Upright row   | Cable lateral raise   | Avoid impingement position |

## Goal -> Action -> Example

- Goal: Keep training while shoulder calms down
- Action: Replace heavy overhead with pain-free pressing and pulling
- Example: OHP 4x6 replaced by landmine press 4x10 + chest-supported row 4x10 for 3 weeks

## Return-to-Load Progression

1. Start with pain-free ROM and tempo control
2. Add reps first for 1 week
3. Add small load increase next week
4. Re-test original movement only if pain stays 0-2/10

## Stop and Refer Immediately If

- Pain is worsening session to session
- Joint gives way, locks, or clicks with pain
- Numbness, tingling, weakness, or radiating pain appears

# Adherence Coaching Playbook: Plateaus, Missed Workouts, Motivation Dips

## Core Rule

- Consistency beats intensity spikes
- Solve behavior first, then optimize program details

## Plateau Management

## Problem -> Cause -> Fix

| Problem                           | Common Cause                | Fix                                           |
| --------------------------------- | --------------------------- | --------------------------------------------- |
| Weight not dropping for 2-3 weeks | Hidden calories, low steps  | Track intake 7 days, increase steps +1500/day |
| Strength stalled                  | No deload, poor sleep       | 1 deload week, then resume progression        |
| Muscle gain stalled               | No overload and low protein | Rebuild progression plan + protein target     |

## Missed Workout Recovery

## Goal -> Action -> Example

- Goal: Avoid all-or-nothing mindset
- Action: Use next-best session rule within 24 hours
- Example: Missed full lower day -> do 30-minute essentials: squat pattern, hinge, core

### Missed Session Decision Table

| Situation       | Action                                       |
| --------------- | -------------------------------------------- |
| Missed 1 day    | Continue plan; do not double volume next day |
| Missed 2-3 days | Resume with 80% volume first week            |
| Missed 1+ week  | Re-entry week at 60-70% load                 |

## Motivation Dip Protocol

| Step | Action                                              | Time                   |
| ---- | --------------------------------------------------- | ---------------------- |
| 1    | Reduce friction (prepare clothes, bottle, playlist) | 5 min night before     |
| 2    | Commit to minimum session                           | 20 min rule            |
| 3    | Track completion, not perfection                    | Daily check mark       |
| 4    | Reward consistency                                  | Weekly non-food reward |

## Behavioral Anchors (Pakistan Context)

- Train right after work/school before traffic delays
- Use nearby local gym even if basic equipment
- Pair gym with fixed routine: prayer time block, commute slot, or friend accountability

## Quick Scripts for AI Coach

- If user says: I missed 3 workouts
- Reply pattern: Normalize -> Simplify -> Commit
- Example: Missing happens. This week do 3 shorter sessions of 35 minutes. Focus on squat, press, row. Start tomorrow 6 pm.

- If user says: No motivation
- Reply pattern: Lower barrier -> First action now
- Example: Wear shoes now, drink water, do warm-up for 5 minutes. Decide after warm-up.

## Weekly Adherence Scorecard

| Metric                     | Target           |
| -------------------------- | ---------------- |
| Planned sessions completed | >= 80%           |
| Daily protein target met   | >= 5 days/week   |
| Sleep >= 7 hours           | >= 5 nights/week |
| Step target met            | >= 5 days/week   |

## Red Flags for Burnout

- Constant fatigue and irritability
- No progress with rising effort
- Persistent poor sleep
- Action: reduce volume 30% for 7 days, maintain movement

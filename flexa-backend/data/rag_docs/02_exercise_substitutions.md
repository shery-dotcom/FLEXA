# Exercise Substitutions by Setup: Home, Dumbbells, Full Gym

## Quick Rule

- Keep movement pattern the same
- Match effort (RPE 7-9)
- Keep similar rep range

## Exercise -> Alternative -> Notes (Lower Body)

| Original Exercise  | Home Alternative        | Dumbbell Alternative | Full Gym Alternative | Notes             |
| ------------------ | ----------------------- | -------------------- | -------------------- | ----------------- |
| Barbell back squat | Backpack squat          | DB goblet squat      | Hack squat           | Keep torso braced |
| Barbell deadlift   | Hip hinge with backpack | DB Romanian deadlift | Trap bar deadlift    | Neutral spine     |
| Leg press          | Wall sit + split squat  | DB split squat       | Pendulum squat       | Control depth     |
| Leg curl machine   | Towel hamstring curl    | DB ham curl (bench)  | Seated leg curl      | Slow eccentric    |

## Exercise -> Alternative -> Notes (Upper Push)

| Original Exercise   | Home Alternative             | Dumbbell Alternative      | Full Gym Alternative | Notes                  |
| ------------------- | ---------------------------- | ------------------------- | -------------------- | ---------------------- |
| Barbell bench press | Push-ups (elevated/weighted) | DB flat press             | Machine chest press  | Full ROM               |
| Overhead press      | Pike push-up                 | DB shoulder press         | Smith OHP            | No lower back arch     |
| Dips                | Bench dips                   | DB close-grip floor press | Assisted dip machine | Shoulder comfort first |

## Exercise -> Alternative -> Notes (Upper Pull)

| Original Exercise | Home Alternative           | Dumbbell Alternative   | Full Gym Alternative | Notes               |
| ----------------- | -------------------------- | ---------------------- | -------------------- | ------------------- |
| Pull-up           | Doorframe row/inverted row | 1-arm DB row           | Lat pulldown         | Pull elbows to hip  |
| Barbell row       | Band row                   | Chest-supported DB row | Cable row            | Avoid jerking       |
| Face pull         | Band face pull             | Rear delt DB fly       | Cable face pull      | Keep shoulders down |

## Problem -> Cause -> Fix

| Problem                  | Cause                        | Fix                                             |
| ------------------------ | ---------------------------- | ----------------------------------------------- |
| Exercise hurts joints    | Wrong variation for mobility | Swap to supported machine or unilateral version |
| No equipment progression | Limited load at home         | Use tempo, pauses, extra reps, unilateral work  |
| Feel wrong muscle        | Poor technique cue           | Reduce load, use 2-second pause at peak         |

## Goal -> Action -> Example

- Goal: Keep chest progress while traveling
- Action: Swap bench press to weighted push-up progression
- Example: Week 1 bodyweight push-up 4x12 -> Week 2 backpack +5 kg 4x10

## Substitution Priority Order

1. Same pattern, same ROM
2. Same pattern, reduced ROM
3. Closest pain-free pattern

## Realistic Pakistan Setup Notes

- Small local gyms often lack machines: prioritize dumbbell compounds
- Load jumps may be large: use rep progression before load jump
- At home: resistance bands + backpack can cover most patterns

## Readiness Checklist Before Substitution

- Can you keep stable spine?
- Can you train near target effort safely?
- Can you progress reps/load/tempo over time?
